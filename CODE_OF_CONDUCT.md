# Code of Conduct

We want a respectful, inclusive community. Harassment or abuse of any kind is not tolerated.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and focus on the issue, not the person.
- Accept feedback gracefully.

## Unacceptable behavior

- Harassment, hate speech, or personal attacks.
- Discrimination or exclusionary behavior.
- Deliberate disruption of discussions or collaborations.

## Reporting

If you experience or witness unacceptable behavior, please report it to the maintainers using a private channel:

https://github.com/init0-lux/vcf-toolkit/security/advisories/new

If you cannot use the advisory form, open a minimal GitHub issue and we will follow up privately.
